# От идеи до прототипа с Клодом


[![hexlet-check](https://github.com/tashantyreva-dot/vibecoding-claudecode-project-438/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/tashantyreva-dot/vibecoding-claudecode-project-438/actions)

Возьмите собственную продуктовую идею и доведите её до прототипа: отсеките
заведомо неподъёмный замысел, поговорите с людьми из сегмента, соберите
из расшифровок доказанные находки, сравните себя с конкурентами и ручным способом,
сформулируйте гипотезы, урежьте объём до пяти-семи пунктов и напишите спеку с
критериями приёмки. В финале нарисуйте прототип в Claude Design и опишите продукт
по формуле из семи строк: для кого, какую проблему решает, чем отличается от
альтернатив и чего не делает.
Главное правило проекта: каждое утверждение о пользователях подкреплено цитатой
из вашей же расшифровки, иначе автопроверка его не пропустит.

Учебный проект Хекслета: https://ru.hexlet.io/programs/vibecoding-claudecode

## Discovery

Материалы исследования лежат в папке [`discovery/`](discovery):

- [`discovery/idea.md`](discovery/idea.md) — заявка на идею и ответы фильтра подъёмности
- [`discovery/interview-guide.md`](discovery/interview-guide.md) — гайд для интервью
- [`discovery/interviews/`](discovery/interviews) — расшифровки интервью
- [`discovery/findings.yml`](discovery/findings.yml) — находки с доказательствами (цитатами)
- [`discovery/competitors.md`](discovery/competitors.md) — сравнение с конкурентами и ручным способом
- [`discovery/pricing.yml`](discovery/pricing.yml) — величина боли, ценовой коридор и цена
- [`discovery/mvp.md`](discovery/mvp.md) — гипотезы с оценкой и объём MVP
- [`discovery/spec.md`](discovery/spec.md) — спека с критериями приёмки и метрикой успеха
- [`discovery/product.md`](discovery/product.md) — описание продукта по формуле
