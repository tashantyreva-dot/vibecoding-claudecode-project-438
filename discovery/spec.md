# Спека

## Задача

Человек регулярно покупает продукты, которые уже есть дома (крупы, специи,
заготовки), потому что не видит всего, что у него уже лежит в кладовке,
холодильнике или морозилке — находка `duplicate-purchases-confirmed` (мама
ездит в магазин без списка и покупает лишнее; сама Татьяна тоже покупает
больше, чем успевает съесть). Продукт делается для одного человека, ведущего
учёт своего домашнего хозяйства, а не для совместного семейного списка.

## Не входит

- Срок годности и цветовой светофор
- Семейный доступ и шеринг списка между несколькими людьми
- Сканирование штрихкодов
- Фото продукта
- Push-уведомления и напоминания
- Импорт, экспорт, облачный бэкап
- Отдельные категории продуктов помимо мест хранения

## Сценарии

**Основной путь**

1. Человек открывает приложение перед походом в магазин
2. Видит список продуктов, которые сейчас есть дома, сгруппированный по
   месту хранения
3. Ищет через поиск конкретное название («есть ли ещё гречка?»)
4. Видит, что гречка есть, и не кладёт её в список покупок
5. Придя домой с покупками, открывает приложение и добавляет новый продукт:
   название и количество
6. Через несколько дней, использовав часть продукта, уменьшает его
   количество или отмечает «закончился»

**Путь с ошибкой**

1. Человек ищет продукт по названию, но вводит его с опечаткой или другим
   словом («творог» вместо «творожок»)
2. Поиск не находит совпадений
3. Приложение показывает пустой результат с понятной подсказкой («ничего не
   найдено — попробуйте другое название») и предлагает посмотреть полный
   список, вместо того чтобы просто показать пустой экран без объяснений

## Критерии приёмки

1. После добавления продукта с названием и количеством запись появляется в
   общем списке без перезагрузки экрана — да/нет
2. Поиск по частичному совпадению названия (например, «мол» находит
   «молоко») возвращает нужный продукт — да/нет
3. Поиск по названию, которого нет в списке, показывает явное сообщение
   «ничего не найдено», а не пустой экран без пояснений — да/нет
4. Список продуктов визуально разделён по месту хранения (кладовка,
   холодильник, морозилка), и продукт виден именно в том разделе, куда его
   добавили — да/нет
5. После отметки «закончился» продукт пропадает из общего списка (или
   переходит в архив, не смешиваясь с текущими) — да/нет
6. Изменение количества продукта (увеличить/уменьшить) сохраняется и
   отображается сразу, без дополнительного подтверждения на отдельном
   экране — да/нет

## Метрика успеха

Из пяти собеседников (мама, Дмитрий, Полинка, alechin, Джипер), с которыми
удастся провести полноценное интервью с прототипом на руках, минимум трое
за первую неделю использования самостоятельно, без подсказки, находят через
поиск продукт, который у них уже есть дома, прежде чем идти в магазин.
